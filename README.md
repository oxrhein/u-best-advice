One sentence, 132 characters, on the best advice I ever received:

> **My father told me never to borrow money to look rich — I still hear him every time an easy loan is offered, and it has kept me free.**

Why this line: it is a real voice recalling a real moment — a father's warning before the world started offering easy loans. It is specific (borrow to look rich), earned (decades of saying no), true beyond the moment (freedom beats appearance in any year), and it lands on the last word: free.

## Run it

```sh
python3 main.py
```

The program writes exactly that one sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset).
